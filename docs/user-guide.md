# Soiree 操作ガイド

> タグ・チーム・シナリオ・機材などのマスタは事前登録済みである前提です。ここでは日々の運用フロー（アップロード → Run作成 → アノテーション → 同期再生 → 作戦ノート）を説明します。

## 0. 最初に：大会を選択する

すべての画面は「現在選択中の大会」に紐づきます。まず画面上部の **大会セレクタ**（タイトル「Soiree」の右）で対象の大会を選んでください。**未選択だとサイドメニューの項目（本番前モード／現場一括アップロード／Run／動画 など）は無効化されます。**

サイドメニュー構成：

- 大会スコープ：ホーム / 本番前モード / 現場一括アップロード / 検索 / 試合 / セッション / Run / 動画 / エンコード状況 / ロボット
- マスタ管理：大会 / チーム / ユーザー / 機材 / シナリオ / タグ

---

## 1. 動画のアップロード

アップロード経路は3つあります。

### A. 動画ページ（通常）

サイドメニュー **「動画」** を開く → 上部で **Session（絞り込み＋アップロード先）** と任意で **Device** を選択してから：

- 破線エリア **「動画ファイルをここにドラッグ&ドロップ」** にファイルを放り込む、または
- **「＋ 動画を選択」** ボタンでファイル選択（複数可、`video/*`）、または
- モバイル/PWAでは **「📷 撮影」** でカメラ撮影 → 即アップロード

### B. 現場一括アップロード（PC・大量向け）

サイドメニュー **「現場一括アップロード」** → **「ディレクトリを選ぶ」** でフォルダ単位選択。フィンガープリントで重複判定し、**「未アップロード」/「アップロード済」** タブに振り分け。未アップロードを選んで一括送信します。HEIC写真は **「HEIC は JPEG に自動変換されます」** の通り自動変換されます。

### 進捗とリジューム

- 右下に **「アップロード状況」** パネルが常駐。ファイルごとの進捗％・速度、✕（中断）/ ↻（再試行）、**「完了/失敗をクリア」** があります。
- tusプロトコルなので、**ページ再読み込みやネット切断後も再開**されます。

### アップロード後に自動で起きること

1. ffprobe が撮影時刻（iPhoneの `quicktime.creationdate` > `creation_time` > GoPro > ファイル更新時刻 の優先順）と尺・サムネイルを抽出
2. videos レコード生成 → HLSトランスコード
3. **撮影時刻が取れなかった場合は要手動設定**

### メタデータ修正（Run作成に必須）

動画行の編集アイコン → **「動画メタデータ編集」** モーダルで：

- **Recorded At**（撮影時刻。未取得時はここで設定）
- **Device**
- **Time Offset（秒）**：カメラ間の時計ズレ補正（小数可）。「補正後の実時刻」に最終値が表示されます

> ⚠️ `recordedAt` が無い動画は壁時計タイムラインに乗らず、Run作成画面で配置できません。必ず先に設定してください。

## 2. Run の作成

**Run = 1回のテストラン**。1つのRunに複数アングルの動画を割り当てられ、逆に1本の長尺録画を時間で区切って複数Runに分割できます。

### 起点

- **動画ページ**：Session選択 → 動画を複数チェック → **「🎬 選択した動画から Run を作成」**
- **現場一括アップロード**：アップロード済から選択 → **「選択動画から Run を作成（別タブ）」**

どちらも `/runs/new-from-videos`（**「選択動画から Run を作成」** 画面）へ遷移します。

### 画面の使い方

1. **デフォルトのメタデータ** カード：Team / Robot / Scenario を設定。「ここで設定した値が新しい区間に流し込まれます。区間ごとに下の表で上書き可。」
   - Team を変えると Robot はリセット。Robot は Team選択後に有効化され、そのTeamのロボットに絞られます。
2. **タイムライン** カード（複数動画を壁時計で整列表示）：
   - 空きの帯を**ドラッグ**して Run区間を作成
   - 区間を**ドラッグで移動**、**端をドラッグで長さ変更**
   - 各動画の上の **アングル名**（正面 / 横 / ドローン 等）はインライン編集可
   - ショートカット：**`[`** = ここからスタート、**`]`** = ここまで、**Space** = 再生/停止
3. **プレビュー** プレイヤー：最大4分割で再生。**「▶ 再生」/「■ 停止」**、スライダーでシーク。区間が覆わない動画は「NO VIDEO」表示。
   - 区間未選択時：**「[ ここからスタート」** → **「] ここまで」** で新区間作成（最低0.5秒）
   - 区間選択時：**「[ 選択 Run の開始をここに」/「] 選択 Run の終了をここに」**
4. **Run リスト** テーブル：各区間ごとに 開始時刻 / 長さ / **Team / Robot / Scenario（必須・上書き可）** / Score / Memo / ✕削除。

### 作成

全区間で Team/Robot/Scenario が埋まり、各0.5秒以上なら **「{N} 本の Run を作成」** が有効化 → クリックで一括作成し `/runs` へ。

## 3. アノテーションの付け方

Soiree には「Marker（タイムライン上のイベント）」と「Annotation（映像へのマークアップ）」の2系統があります。**いずれもDB保存され、同じRunを開いている他メンバーにリアルタイム反映されます。**

### 3-1. Marker（イベント記録）

Run詳細ページの **Markers** セクションで：

- 動画を目的の時刻で止め、**「現在時刻 HH:MM:SS に追加:」** の行に並ぶ種別ボタン（大会ごとに事前定義した種別）をクリック → 即追加
  - ※種別未登録だと「この大会には Marker 種別が未登録です。大会編集画面で追加してください。」と表示
- **「＋ 詳細追加」** → モーダルで **位置（秒）/ 種別 / Label** を指定して追加
- 下部テーブル（Time / 種別 / Label）で時刻クリックでシーク、編集・削除が可能。種別チップで絞り込み表示。

### 3-2. Annotation（映像への描き込み）

動画ページの ▶（動画再生＋Annotation）や Run の再生ビュー上部の **AnnotationToolbar** から：

- **📍 Point** … クリックで1点
- **▭ Rect** … ドラッグで矩形
- **➝ Arrow** … 始点クリック→終点ドラッグ
- **🅣 Text** … テキスト（ラベル必須）
- **✏️ ライブインク** … リアルタイム描画。保存されず数秒でフェード（ミーティング中の指し示しに便利）

各アノテーションは表示する **開始/終了（秒）** の時間帯を指定可能。下部テーブル（開始 / 終了 / Type / Label）で管理。**「🖼 PNG エクスポート」** で現フレーム＋表示中アノテーションを画像保存できます。ユーザーごとに色が割り当てられ、作成者が区別できます。

## 4. 同期プレイヤー（SyncPlayer）

複数アングルを**撮影時刻ベースで完全同期**再生。Run詳細ページ最上部に表示されます。

- レイアウト：左にメイン映像、右にサムネイル（クリックでメイン切替）
- 操作：**▶ Play / ⏸ Pause**、スライダーでシーク（全アングル一括）。スライダー上のカラードットはMarker（クリックでジャンプ）。
- カメラ間の時計ズレは、メタデータの **Time Offset（秒）** やアングルごとのオフセット編集で補正します。

### 複数人での同期視聴（Presence）

- **「🛰 全員に追従させる」** … 自分の再生/シークを全員に配信。配信中は **「🛰 自分に追従中 (停止)」**
- 他者が配信中なら **「🛰 自分に追従させる (奪う)」** で配信権を奪取
- スライダー下の **Presence Strip** に各メンバーの再生位置が色付きで表示。特定ラインをクリックでその人を個別追従。

## 5. 作戦ノート（Scouting Note）

Tiptap + Yjs + Hocuspocus による**リアルタイム共同編集**のリッチテキストメモです。

### スコープと場所

- 単位：**大会 × チーム**（同じチームでも大会が違えば別ノート）
- アクセス：**Run詳細ページ**下部、または **「本番前モード」→ 試合 → マッチアップ** ページ（対戦両チームのノートを左右に並べて表示）

### 編集

- エディタに直接入力（リッチテキスト：太字・リスト・見出し等）。自動同期・保存。
- 上部に **「リアルタイム同期 (Hocuspocus)」** と接続バッジ（connected=緑 / connecting=黄 / disconnected=赤）。同期待ちは syncing 表示。
- 切断時は「Hocuspocus に接続できません。`docker compose up -d hocuspocus` で…」と案内。

### Marker リンクの埋め込み

1. カーソル位置で **「📍 Marker を挿入」** をクリック
2. **MarkerPickerModal** で対象Run・Markerを選んで挿入
3. 本文中のリンクをクリックすると、動画プレイヤーが該当Markerの時刻へジャンプ

複数人が同時編集してもCRDTで自動マージされ、ユーザーごとの色付きカーソルで「誰がどこを編集中か」が分かります。
